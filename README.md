<P>About

This project is a classic Tic-Tac-Toe game developed using HTML, CSS, and JavaScript. It provides an interactive and user-friendly interface where two players can compete on a 3×3 grid. The game automatically tracks turns, detects winning combinations, identifies draw situations, and offers a smooth gameplay experience across different devices.

Features
Interactive 3×3 game board
Two-player gameplay
Automatic win detection
Draw detection
Responsive design
Clean and intuitive user interface
Lightweight and easy to run in any modern browser
Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
Objective

The goal of the game is to place three identical symbols (X or O) consecutively in a row, column, or diagonal before the opponent does.
