## 📖 About

This project is a classic **Tic-Tac-Toe** game developed using **HTML, CSS, and JavaScript**. It provides an interactive and user-friendly interface where two players can compete on a **3×3 grid**. The game automatically tracks turns, detects winning combinations, identifies draw situations, and delivers a smooth gaming experience across different devices.

## 🎯 Objective

The goal of the game is to place **three identical symbols (X or O)** consecutively in a:

- Horizontal Row
- Vertical Column
- Diagonal Line

before the opponent does.

---

## 🎲 Game Flow

```text
Player X Starts
       ↓
Select Empty Cell
       ↓
Player O Turn
       ↓
Check Winning Combination
       ↓
Winner Found ? ── Yes ──► Game Ends
       │
       No
       ↓
Board Full ?
       │
      Yes
       ↓
      Draw
```
